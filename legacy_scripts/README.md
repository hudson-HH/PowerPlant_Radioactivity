# Historical scripts

These scripts preserve the original research code as a historical record. They
reference the original local research tree, including absolute personal paths,
external frozen inputs, checkpoints, and exploratory branches. They are not part
of the `run_all.R` entry point and are not a portable pipeline.

Directory and file names have been translated to English; see
`../provenance/renamed_paths.csv`. Script bodies retain original external-tree
path names so that the historical configuration remains interpretable. These
external paths do not point to the renamed archive copies in this repository.
Supply the original external inputs and adapt paths before intentionally using
a historical script. No historical analysis was run during repository preparation.

Original source-script hashes in the provenance manifests identify the input
archive versions. `../SHA256SUMS.txt` identifies the final distributed files.
